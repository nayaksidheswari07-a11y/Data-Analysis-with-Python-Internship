# Superstore Sales Data Analysis

## Project Overview
This project analyzes Superstore sales data using Python and Pandas.

## Work Done
- Data cleaning and preprocessing
- Missing value and duplicate handling
- Exploratory Data Analysis (EDA)
- Sales and profit analysis
- Data visualization using charts
- Cleaned dataset exported to Excel

## Files
- `Superstore.csv.xls` – Original dataset
- `cleaned_superstore.xlsx` – Cleaned dataset
- `Superstore_analysis.py` – Python analysis script

## Tools Used
- Python
- Pandas
- Matplotlib
- Excel
- GitHub
